# Hifza Technical Services Website

A responsive static website for Hifza Technical Services, designed for GitHub Pages.

## Files
- `index.html` — website
- `style.css` — design/responsive layout
- `script.js` — mobile menu + current year

## Before going live
Replace the demo phone, WhatsApp number, email and location in `index.html`.

## GitHub Pages
1. Create a GitHub repository (for example `hifza-technical-services`).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your free `github.io` website address.
